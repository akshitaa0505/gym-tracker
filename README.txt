Gym Tracker website

This folder is the gym-tracker GitHub repository.
Netlify deploys it automatically whenever a change is pushed to the main branch.

Files
- index.html          the app
- supabase.js         Supabase client library (591.supabase.js is part of it)
- manifest.webmanifest, *.png   home-screen name and icon

Data lives in your Supabase project (table: public.workouts).
Sign in with the user you created under Authentication > Users.
